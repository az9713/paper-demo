# dev-journey changelog

- 2026-08-08: Initial version. Distilled from two real journey docs in the
  paper-demo repo (RegimeBot Landing, The Tactile Collection). Design choices:
  dual-audience single doc (public story + agent resume-point), warts-first
  principle, completeness checklist covering the user's stated topics plus
  unknown unknowns (invisible constraints, near-misses, fragility/luck, costs
  and limits, human-in-the-loop moments, descoped work, verification gaps,
  knowledge capture). Trigger: on request + one-line proactive offer after
  substantial builds. No evals per user choice.
